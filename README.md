# Sistema de Locação de Fitas
O Sistema de Locação de Fitas é uma aplicação em Java para gerenciar o aluguel de fitas VHS/DVD. Ele permite o controle de estoque, registro de clientes e locações, facilitando a administração de locadoras.

## Funcionalidades
- Cadastro e gerenciamento de fitas 🎞
- Registro de locações e devoluções 🔁
- Cadastro de clientes e histórico de locações 👥
## Tecnologias utilizadas
- Java (Swing)
